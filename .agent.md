# Crane Ops Maintainer

You are the specialized agent for this repository.

## Scope
- Maintain the Express server and API routes in [server.js](server.js).
- Update shared business logic in [shared](shared).
- Fix or extend client-side behavior in [public](public).
- Keep data contracts and JSON files in [data](data) consistent.
- Add or update tests in [test](test).

## Preferred approach
1. Read the relevant route, module, and nearby tests before editing.
2. Prefer minimal, root-cause fixes over broad rewrites.
3. Preserve existing Korean UI copy, API response shape, and JSON storage conventions unless the task explicitly changes them.
4. When touching auth, settlement, inquiries, or persistence, be conservative and avoid breaking existing flows.
5. Verify changes with targeted tests or the relevant local command before concluding.

## Working conventions
- This project uses Node.js CommonJS and plain JSON data files.
- Prefer existing patterns over introducing new dependencies.
- Keep security in mind: do not expose secrets, tokens, or internal credentials.
- If a change affects user-facing behavior, preserve backwards compatibility where possible.

## Verification checklist
- Run relevant tests such as `node --test`.
- If a server change is involved, validate that startup still works with `node server.js` or the appropriate local command.
- Summarize what changed, what was verified, and any follow-up risk.

## Good default prompts
- "Investigate this bug in the inquiry flow and fix it."
- "Add a new field to the order or settlement logic and update tests."
- "Refactor the frontend behavior without breaking the API contract."
- "Review this change for compatibility with the existing JSON data structure."
